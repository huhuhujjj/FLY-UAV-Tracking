# 项目开发与验收记录

本目录保存贯穿项目的开发步骤、决策、配置检查和阶段验收证据。已有 `2026-11-17_step1.md` 与定义验证记录；它们只证明第一步定义检查，不证明模型或网页功能通过。

后续每项开发工作记录日期、目的、执行命令、输入与版本、实际结果、错误及修复、证据路径和下一步。模型训练与评估的详细运行产物放在 [`../model/experiments/`](../model/experiments/README.md)，网页后端运行日志放在 [`../web/backend/logs/`](../web/backend/logs/README.md)，并在本目录的开发记录中引用对应路径或运行 ID。

`experiment_template.json` 是待复制填写的模板，不是一次已完成实验。
