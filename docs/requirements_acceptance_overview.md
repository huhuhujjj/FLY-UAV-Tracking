# 首轮需求与验收总览

版本：SRS 1.2 定义整理，2026-11-17。此表是 [19 项详细验收映射](acceptance_matrix.csv) 的阅读入口。状态均为 `NOT_EXECUTED`，不表示功能已经实现。

| 需求 | 固定定义 | 验收方式与证据 | 详细用例 | 状态 |
| --- | --- | --- | --- | --- |
| 类别 | 首轮仅 `car`（小汽车）、`bus`（公交车/客车）、`truck`（卡车）。`van`、人员及其他类别不得自动并入 `car`；VisDrone/COCO 源编号仅为候选，须核对官方类别表及 DET/MOT 标注。 | 检查源标注、类别映射和转换前后计数；保留排除与 ignore 记录，独立抽查样本。 | AT11、AT12 | NOT_EXECUTED |
| 输入模式 | 单张 JPEG/PNG 图片只做检测和当前帧摘要，不生成跟踪 ID 或轨迹；录制 MP4 视频做逐帧检测、**视频任务内**跟踪和有限摘要。 | 分别输入图片、视频及无目标样本；检查结果 JSON、标注媒体和任务记录；连续两视频验证 ID 不继承。 | AT01、AT06 | NOT_EXECUTED |
| 用户与任务 | 本地单用户，服务只绑定 `127.0.0.1`；一次接收一个文件，同时最多一个非终态任务。非终态为 `VALIDATING`、`QUEUED`、`RUNNING`、`FINALIZING`。 | 在四个非终态分别并发提交，必须返回忙碌且不创建第二任务；终态后能提交新任务。 | AT03、AT13 | NOT_EXECUTED |
| 固定场景摘要 | 图片/视频均可输出逐帧所选类别可见数量和左/中/右区域数量，来自有效检测框；区域由源图像宽度归一化的框中心决定，边界归右区。视频另输出临时轨迹的首末观测时间、观测片段与缺口，来自源帧号/时间戳和逐帧关联记录；图片不生成时序结论。每条摘要保留任务、帧、时间、检测/临时跟踪 ID、规则版本及可回查证据。无目标帧也保留；不能用预测填补缺失观测。 | 手工构造空帧、区域边界、未关联检测和缺口样例；再用独立人工框/ID评价计数、区域、时间误差及无依据陈述率。 | AT16a、AT16b | NOT_EXECUTED |
| 文件与边界 | 候选输入为 JPEG/PNG 图片和可解码 MP4 录制视频。配置初稿暂列图片 15 MiB、4096×2160；视频 200 MiB、120 秒、1920×1080、30 FPS。**这些数字及编码支持尚未验证，不是最终上限。** | 用真实解码器和浏览器测试边界内外、损坏及伪装文件；先导后冻结限制，拒绝时给明确错误，不静默截断。 | AT01、AT02 | NOT_EXECUTED |
| 版本与评价 | 每次运行记录代码提交或未提交状态、数据清单与哈希、模型架构/权重来源与哈希、跟踪器及参数、完整配置哈希、评价数据划分与哈希、评价器名称/版本/匹配和 ignore 规则、依赖和设备、命令及实际结果。验证集选参，最终测试集冻结。 | 检查每个运行 ID 的完整记录、数据划分和可复现命令；用相同检测器比较跟踪器，最终测试不得用于选参。 | AT11、AT12、AT17、AT18 | NOT_EXECUTED |

数值模型阈值、跟踪参数、准确率与性能目标均为 **`PENDING_PILOT`**。先导试验与数据审计完成前，不填写“通过”或测得分数。当前系统只有静态网页样机。
