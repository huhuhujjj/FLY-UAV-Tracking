# 第二部分动手练习：核对标注与数据划分

这项练习只需约15分钟。你负责判断画面与标注是否一致；批量下载、统计、哈希、转换和重复筛查由脚本完成。无需安装软件、训练模型或修改原始标注。所有图像来自本地VisDrone先导样本，审核结果只用于改进审计规则，不会直接把样本放入最终测试集。

## 先看懂双栏图

每张图左栏是原标注，右栏是把源框转换为YOLO格式后再画回原图的框。青色是car，黄色是bus，紫色是truck；左栏红色为源忽略区域。右栏只显示项目的car、bus、truck，所以van、行人和忽略区域不会出现。请核对同一辆车在左右栏的位置、大小和类别是否一致，而不是判断模型预测好坏：这些框全是数据集标注。

1. 打开[图片标注回绘](../.qa/step2_data/DET_0000153_0000153_00801_d_0000001.jpg)。找黄色bus框，再找一处左栏红框。检查bus在左右栏是否对齐，红框是否只留在左栏。

3. 打开[源ID冲突前的第878帧](../.qa/step2_data/MOT_uav0000268_05773_v_0000878.jpg)与[冲突后的第951帧](../.qa/step2_data/MOT_uav0000268_05773_v_0000951.jpg)。原标注将同一序列的ID 15先标truck、后标car，中间72帧没有该ID观测。看看图像能否支持“同一个真实目标”的判断；若看不清，请明确写“无法判断”。不要依据相同ID直接认定同一辆车，也不要自行修改类别。

ID 15写在标注文件中，并非车身上的可见编号。图片较小或目标在画面边缘时，回答“无法判断”完全正确。要判断是否为同一真实目标，需要更连续的原始帧和独立复核；本练习不要求你猜测。

## 回复格式

复制下面三行，填“是 / 否 / 无法判断”并加一句原因即可：

```text
1. bus框对齐、红色忽略区域没有被转成目标框：是____；原因：____
2. DET与MOT篮球场属于相同或关联来源：_是___；原因：____
3. 仅凭第878和951帧能确认ID 15是同一真实目标：_无法判断___；原因：_太小无法识别id号___
```

第3题回答“无法判断”是有效的审计结论。我们会保留原标注并隔离该序列，直到有连续源帧或独立标注证据。你的反馈会记录在人工复核表；正式训练/验证/测试清单仍须完成全量来源审计后才能冻结。
