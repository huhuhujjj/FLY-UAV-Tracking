## 检查结果与发现

7项手算/异常用例通过：手算坐标、三类映射、ignore/van/others排除、MOT帧号/ID/属性无损、边界不静默裁剪、ID 0及坏标注拒绝。61张图的转换往返检查通过；10张回绘进行了Codex目视抽查，涵盖car、truck、bus、van排除、无目标、夜景、密集遮挡及冲突证据。其余51张回绘尚未目视抽查，不能称为独立人工真值复核。抽查清单在`../.qa/step2_data/visual_review.csv`。

1. **跨任务关联候选 DATA-001：**DET 0000086与MOT uav0000086的首两帧dHash距离为0，目视可见同一篮球场场景。文件与原始像素哈希不同，所以字节去重无法发现这类来源风险。相关来源作为一组隔离；不能只按图像文件名随机划分。
2. **源ID类别冲突 DATA-002：**uav0000268_05773_v，ID 15在731–878帧为truck（6），951–978帧为car（4）；879–950没有该ID观测，首个类别变化位于源标注第4052行。不能自行认定为同一真实目标、用预测修正或静默拆分ID。该序列暂不作为冻结跟踪主验收真值，须独立复核或正式排除并披露。
3. **许可版本 DATA-003：**官方数据保护页面写明学术用途及CC BY-NC-SA 3.0，正文明确提到VisDrone2021；本次包名为2019。已取得官方许可条款证据，但与这两份2019压缩包的版本适用关系尚待核实。工具箱的research-only代码声明不能替代数据许可。

跨任务检查只覆盖15×46个已下载图像对；精确重复0组，dHash≤8候选2组。没有候选不证明来源独立。并未审计完整训练集或最终评价集，也没有测试模型。

本轮纯数据工具使用Codex捆绑Python 3.12.14与Pillow 13.0.0；不加载PyTorch或模型，不使用系统Python 3.14或旧虚拟环境。运行时完整路径和版本见日志及实验记录；项目未来推理/训练仍使用专用Docker环境。Windows当前Docker引擎未运行。

python model/scripts/fetch_visdrone_pilot.py
python model/scripts/audit_visdrone.py
python -m unittest discover -s model/tests -p test_visdrone_audit.py -v
