# 第一步 验收定义与实验范围

编制日期：2026年11月17日。SRS 1.2。第一步定义材料已建立，系统功能与性能测试仍未执行。

## 固定范围

本机单用户、单个JPEG/PNG图片或MP4录制视频、至多一个非终态任务。图片检测并生成当前帧摘要，视频检测、任务内临时ID跟踪及有限摘要。首轮固定语义为car、bus、truck；下载版本和MOT评价共同类别核验前，不将源编号标记为已验证。van等其他类不静默并入car。数据不可支持既定类别时，应记录阻塞或正式改范围，不自行认定满足。

不含直播、飞行控制、地理定位、真实速度、人脸/车牌、跨视频身份、ReID训练、拥堵/违停/事故、风险决策、道路语义分割和任意视频问答。不强求实时；离线处理耗时必须实测。当前前端仍为静态样机。

## 三层验收口径

识别：检测框和类别对照独立人工真值，报告每类Precision、Recall及mAP50、mAP50至95；固定IoU匹配、置信度操作点、ignore规则、指标尺度及工具版本。不能以模型置信度代替准确率。

跟踪：在真实跨帧ID上报告HOTA、IDF1、MOTA、IDSW及断轨；分帧号、类别、忽略区域适配未验证时不认定分数有效。临时ID和轨迹段不等于身份或真实唯一车辆数。评估ID关联与应用ID分配分开记录。

场景摘要：仅含每帧所选类别可见数量、图像左中右分布，及视频临时目标可见时间和观测缺口。按框中心cx/源宽度划分：[0,1/3)、[1/3,2/3)、[2/3,1]；边界归右区。未关联检测仍计入可见数量，ID为空。相机移动时不将像素位移称为地面运动。全帧空目标记录不可省略。

所有摘要保留job_id、源frame_index、源timestamp、依据检测记录和规则版本；图片时间字段为空。轨迹只连接逐帧真实检测观测；缺少连续源帧观测即标记缺口，不以tracker预测补作事实。后续重现相同ID仍不保证真实身份恢复。

先用手工小例验证逻辑，再用独立人工框/ID通过冻结规则生成参考计数与时间。计数报告各类MAE及区域计数误差，时间误差在已一一匹配轨迹上计算并同时披露未匹配、误关联、ID切换及标注采样间隔。抽样人工逐条核查摘要陈述，报告错误/无依据条数、总条数及比例；无陈述时比例记为N/A，不假记0。没有可评样本的指标不得标记通过。

## 实验设计

检测基线是COCO预训练YOLO26在公共三类上的映射；实验为同模型规模的VisDrone微调版本。再在验证集比较可运行的较大YOLO26候选与输入尺寸。首选精度但必须记录显存、训练预算与端到端耗时，不保证最大模型最佳。支持的具体权重名称、模型大小和尺寸在环境试验后固定。

跟踪采用ByteTrack基线和BoT-SORT对比，使用同一检测器及序列。训练、验证调参、最终测试按源序列隔离，核查DET/MOT潜在重叠。无法排除的关联样本不纳入主要独立测试。模型/阈值/摘要区域规则只在验证集选择，最终测试不选优；算法不得把预测当人工真值。

## 待先导冻结项目

输入大小/时长/分辨率/FPS及编码支持、具体权重、输入尺寸、batch、epoch、随机种子、检测阈值、跟踪参数、准确率/跟踪/摘要误差绝对门槛、抽查规模和运行响应目标均未实测。configs中的候选输入值来自既有SRS，仅为待测目标。详细数值门槛放model/configs/acceptance_targets.json，目前为null；在最终测试前且按G3要求记录先导依据和冻结清单，否则禁止声称最终通过。

定义冻结不等于数值门槛或性能通过。下一步下载小样本核验类别、标注和许可，未获得数据前不编造样本数。某类在独立测试没有足够有效标注时列为不可评价并处理，不用总体高分掩盖。

## 产物与使用顺序

先读本文，再读model/configs/project_scope.json、model/configs/classes.json、model/configs/acceptance_targets.json及docs/acceptance_matrix.csv。每次运行复制logs/experiment_template.json生成新的运行ID，填写命令、代码/数据/权重哈希、设备、预期、实际、错误和证据。验证器model/scripts/validate_step1.py仅检查定义文件完整性；它不执行模型或证明系统功能通过。Gantt与附录不因本次步骤定义而修改。
