# 第二部分接手完成记录

日期：2026-11-19。

用户将剩余技术操作委托给助手。本轮沿用动手指南的建议选项形成技术快照：异常与来源风险按整个数字前缀组件隔离；首轮 DET 训练候选限定为不含 ignore、others、score=0 记录的图像；验证采用既有本地忽略框并集覆盖至少50%规则，不称官方分数；MOT评价适配留到G2。助手的技术选择不是学生本人签署，不代表许可已确认。

## 交付文件

- `model/data/manifests/step2_technical_v1/policy.json`：本轮技术规则与限制。
- 同目录 `media_inventory.jsonl`：逐图片/帧的ZIP内部路径、来源组件、候选阶段、排除原因、源标注SHA-256、压缩包SHA-256、成员CRC和长度。
- 同目录 `verification.json`：数量、输入哈希和整包哈希核对结果。
- 同目录 `SHA256.json`：本轮技术快照及异常证据索引的内容摘要。
- `.qa/step2_anomalies/index.html`：37条异常记录的原图与标注行证据；红圈仅定位异常框起点，不是修正框或模型预测。
- `model/scripts/build_step2_technical_snapshot.py`：可重复生成上述输出的标准库脚本。

图片原件在 `model/data/raw/archives/*.zip`；`raw/DET-*`、`raw/MOT-*` 中的先导提取目录不代表完整媒体已解压。审计直接读取ZIP成员。异常页提取单图副本并记录SHA-256，不修改源包。

## 核查与限制

本轮运行指南规定的 corpus、full_media、ignore 三项检查：关键项均PASS。原有9份同步文档哈希核对通过。来源组件仍为训练169、验证45、最终测试64、隔离52；全量42,311图/帧；异常框37条。

快照生成额外校验六个ZIP的实际SHA-256和所有媒体所对应源标注哈希，核对媒体键唯一性和37条证据导出数量。成员CRC不是成员独立的密码学哈希；整包SHA-256与ZIP成员路径共同定位具体源文件。来源前缀及感知哈希不能证明绝对独立。

本轮没有正式冻结评价清单，G1仍未通过。2019 DET/MOT许可版本适用性仍待发布团队回复；用户报告已发送询问。没有回复不能补造批准或代签。许可明确后应核对本快照规则与用途，再生成正式发布版本。MOT评分适配、实际预测过滤及官方工具对照在G2验证；没有模型结果，不宣称官方分数等价。若许可或后续验证改变政策，须升版并重算清单，禁止依据最终测试得分改样本。

当前系统仍是静态网页样机；本轮只整理数据技术证据，没有训练、推理或系统验收结果。原操作指南仍可用作学习材料，本记录说明用户委托助手接手后的实际输出。
