# VisDrone许可版本核验

2026年11月17日，经网页工具核验 https://aiskyeye.com/data-protection/ 。官方正文标注VisDrone2021，限定学术用途，提供CC BY-NC-SA 3.0链接并要求署名、非商业及相同方式共享。下载页 https://aiskyeye.com/download/ 表示2024 DET数据与2019相同；这不足以单独证明2019 MOT压缩包的许可适用性。保留版本适用核查项，不将工具箱代码许可证或第三方镜像许可证替代原数据条款。

网页脚本请求403；本文件是基于网页工具读取的核验摘要，不是原HTML快照。官方README原文快照及下载文件哈希见邻近文件和manifests/pilot_acquisition.json。当前只在本机开展学术项目先导检查，原始图片和派生标签保持本地，不发布到代码仓库。

2026年11月18日补充核验：[官方2020测试说明](https://aiskyeye.com/evaluate/test-guidelines/)及[官方2024测试说明](https://aiskyeye.com/test-guidelines-2022/)均禁止用VisDrone测试集训练，并禁止在一个竞赛任务中用另一个任务的训练或验证集训练；[官方FAQ](https://aiskyeye.com/faq/)说明“others”和忽略区域内的检测会在官方评价中按其规则过滤。本项目的来源关联清单仅用于隔离泄漏风险，不能据此把DET/MOT样本合并成跨任务训练集。课程本地评价若不用官方服务器，也须单独写明评价规则，不能声称与官方成绩可直接比较。2019压缩包的精确许可版本适用性仍待确认。

本地六套完整压缩包的文件名目录已检查，没有独立的LICENSE、LICENCE、COPYRIGHT或README成员；该事实不能替代发布方的授权说明。继续保持原始媒体及派生标签仅限本机课程审计，不发布或再分发。

已备妥`docs/visdrone_2019_terms_query.md`供学生核实2019 DET/MOT条款、派生标签、课程报告插图和署名要求。学生于2026年11月18日报告已发送询问；本地未取得实际发件记录、邮件原文或发布团队回复。版本适用性继续标记为待确认。

较新官方版本与当前2019基线的任务覆盖比较见`docs/step2_dataset_version_review.md`。询问草稿已补充请求较新且同时具备静态DET与MOT的数据链接及其版本条款，未据此改变当前数据来源。
