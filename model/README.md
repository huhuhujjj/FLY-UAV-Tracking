# 视觉模型工作区

本目录管理 YOLO 航拍车辆检测、视频内跟踪、数据审查及评价工具。当前使用 YOLO26l 预训练权重与 ByteTrack 跑通离线图片/短视频流程，并由本地 Web 服务调用。数据审查记录见后文；G1 未标记为通过，最终测试清单尚未冻结。模型微调、代表性定量评估和正式系统验收尚未完成。

| 目录 | 用途 |
| --- | --- |
| `src/` | 推理、跟踪、数据规则及评价代码，由 `web/backend/` 或离线脚本调用。 |
| `scripts/` | 数据获取、审查、转换、离线运行、评价及文档清单工具。 |
| `configs/` | 现有项目范围与验收定义；以后加入模型、数据和跟踪器配置。 |
| `data/` | 原始数据、转换后数据及标注，按来源和版本记录。 |
| `weights/` | 预训练与训练得到的模型权重。 |
| [`experiments/`](experiments/README.md) | 未来每次模型运行的配置快照、指标、图表和错误分析。 |
| `tests/` | 模型组件和数据转换的测试。 |

原项目的配置、数据、脚本和测试目录已统一迁入本目录。现有配置仍是项目范围与验收定义；现有脚本包含文档检查及数据审计/转换，不代表模型训练已实现。

项目开发过程记在 [`../logs/`](../logs/README.md)；网页后端的运行日志预留在 [`../web/backend/logs/`](../web/backend/logs/README.md)。

数据与权重可能很大，默认不提交 Git。提交可复现的来源、许可、下载/转换脚本、配置、依赖版本及实验摘要；实际下载和训练后再填写结果。模型类别映射、阈值和性能目标以先导实验冻结后的配置为准。

## 第二部分全量媒体审计进展

2026年11月18日第二部分全量媒体进展：六套VisDrone2019 DET/MOT压缩包均已完成SHA-256和ZIP CRC校验，逐图/逐帧解码共42,311张。源标注框相对媒体尺寸发现37条越界或非正记录，原文件未改动，相关来源暂隔离。

跨拟议阶段的解码像素哈希相同指纹组为0组。dHash距离不大于4、但文件名数字来源前缀不同的候选配对为73对，涉及六组前缀配对；均已逐组查看原始分辨率候选帧，所见固定地标不同。感知哈希只是筛查线索，未据此宣称所有来源独立。当前隔离52个来源组件，训练、验证及最终测试仅为候选，均未冻结。

官方VisDrone测试说明禁止用测试集训练，也限制把一个竞赛任务的训练/验证数据用于另一个任务训练。本项目的跨DET/MOT来源比较只用于泄漏审计；test-dev只用于完整性和来源风险检查，不用于选优。已建立三类本地忽略区域规则先导：DET-val来源候选407张，原始目标10742框中按忽略覆盖排除22框，保留bus126框；未运行模型，且尚未与官方MATLAB评价逐项对照，不能称官方分数等价。普通YOLO转换标签仍只是审计产物。

学生已目视复核bus框、忽略区域及DET/MOT篮球场关联；对于第878和951帧的ID 15，因目标太小而无法判断是否同一真实目标。学生又确认近重复对照图第5、6行各自左右样本不关联；扩展查看第5组其他候选帧也显示不同固定地标。临时轨迹ID不代表真实身份。

证据见docs/step2_corpus_annotation_review.md、docs/step2_ignore_policy_pilot.md、docs/step2_dataset_version_review.md、model/data/manifests/及model/data/sources/licence_review.md。2019是当前可审计的DET/MOT基线，不宣称最新；官方2024 DET与2019相同，2023/2024核心任务未列MOT，较新完整版本仍需核实。未命中来源的关联风险、2019压缩包许可条款适用性、训练政策冻结及与官方评价的等价性仍待处理；G1未通过，最终测试集未冻结。网页仍为静态样机，没有训练、推理、跟踪或系统验收结果。原有SRS范围、甘特图及附录不变。
## 第三部分离线最小技术链路进展

2026年11月19日按开发计划草稿第三步跑通离线最小技术链路，项目版本0.2.0-alpha.1。第二部分数据审计和划分的技术准备已完成；许可版本适用性继续待跟进，不再作为整个毕业项目停工条件。既有G1未通过标记不改写成已通过；最终测试清单仍未冻结，未执行训练或最终测试。

使用官方COCO预训练YOLO26l和ByteTrack，实现单张JPEG/PNG检测，以及单个恒定帧率MP4的逐帧检测、视频内临时ID和图像轨迹输出。导出标注图片/视频、逐帧JSONL、检测CSV、轨迹JSON及运行状态；图片不分配轨迹ID。每段视频新建跟踪器；缺帧不补造观测，轨迹只连接连续观测。

开发样本来自未隔离的验证候选：一张DET图片及MOT序列uav0000117_02622_v的连续48帧。短片编码为25 FPS，仅为选定的检查播放速率，原始采集FPS未核实。解码帧号0至47对应源帧号1至48；时间戳来自媒体PTS并以首帧归零。Windows专用环境和Docker均完成CPU/GPU图片、视频运行；媒体、坐标、CSV/JSON、哈希和时间轴检查通过，同进程重复视频记录一致。

24项数据与手算评价测试通过，覆盖完美匹配、ID切换、缺失观测、类别错误、忽略区域、ID 0和空分母。检测采用pycocotools，跟踪采用TrackEval 1.3.0并按类别计算IDF1、HOTA、MOTA和IDSW；这是项目本地忽略规则评价，不是官方VisDrone等价分数。发现整帧无预测时TrackEval断轨计数与手算不一致，故Frag置空，原始值仅供排查，留待第五步核验。

本轮真实预测只用于链路检查。48帧中存在漏检、误检及ID切换；没有bus或truck真值，相关比率标记不适用。参数640、conf 0.25及IoU 0.7为未冻结先导值，不是选优结论；低于0.25的检测未输入此轮ByteTrack低分匹配。耗时和PyTorch峰值显存见docs/step3_minimal_pipeline.md及.qa/step3_verification.json，不当作性能验收或代表性准确率。

网页仍是五页HTML/CSS静态样机；离线运行记录不代表已实现网页上传、后端任务、回放筛选、摘要或导出功能。损坏文件记录失败、无目标图片可成功返回空结果；操作系统锁及中断恢复仅用于离线运行。原SRS范围、19项系统验收未执行状态、作者学生导师信息、甘特图及附录保持不变。下一步为第四步模型候选比较与微调，最终测试不参与选优。
