# 前端界面

此目录包含前端页面。当前版本 **0.2.0-alpha.3**。

## 页面结构

- `workspace.html`：**工作台（索引页）**。总入口，展示「图片检测」「视频跟踪」两个可运行入口卡片，点击进入对应功能页。
- `image-detection.html`：**图片检测功能页**。已接入本地后端，固定为图片检测模式；提交单张 JPEG/PNG，展示真实标注图与检测记录（类别/置信度/坐标），提供真实下载。
- `index.html`：**视频跟踪功能页**。已接入本地后端，固定为视频跟踪模式；提交恒定帧率 MP4，展示真实标注视频播放、帧数/时间戳、逐帧检测记录与视频内临时 ID，提供真实下载。
- `app.js`：**共享交互控制器**。通过 `window.APP_MODE`（`image` / `video` / `hub`）决定页面行为；单类型页面自动固定媒体类型、隐藏类型选择器并复用同一套处理逻辑。显示等待/处理中/成功/失败状态，处理中阻止重复提交，支持取消与清空。
- `i18n.js`：**中英双语**字典与切换逻辑。顶栏「English / 中文」按钮切换；语言偏好存入 localStorage，默认跟随浏览器语言（中文环境默认中文）。所有静态文案经 `data-i18n` 标记、动态文案经 `t()` 函数本地化。
- `task-history.html`、`evaluation.html`：占位页面，保留界面结构和未接入数据、未测量的提示；不执行处理。

## 启动

先启动后端（见 `../backend/README.md`），再在浏览器打开：

- 索引页：`http://127.0.0.1:8765/workspace.html`（或直接 `http://127.0.0.1:8765/`）
- 图片检测：`http://127.0.0.1:8765/image-detection.html`
- 视频跟踪：`http://127.0.0.1:8765/index.html`

也可直接双击 `.html` 文件查看静态页面，但此时不会连接后端、无法处理媒体。

## 说明

- 轨迹 ID 仅在当前视频内临时有效，不表示真实身份；轨迹是图像平面观测，缺帧不插值。
- 参数沿用现有试运行配置（conf 0.25 等，未冻结），不作为正式标准或系统性能承诺。
- 本页面只覆盖离线测试最小闭环，未实现筛选、摘要、训练或评估功能。
- 双语范围：工作台索引页、图片检测页、视频跟踪页均提供中英切换；`task-history.html`、`evaluation.html` 仍为中文样机。
